# Seed Data

Status: Development data guide

## Purpose

Seed data should make the app testable and visually realistic without using real personal data.

## Seed Categories

### Countries And Cities

Include common target countries:

- United Kingdom
- United States
- Canada
- Germany
- Australia
- Ireland
- Netherlands
- United Arab Emirates

### Employers

Create sample employers:

- verified sponsor-friendly tech company
- healthcare employer
- engineering company
- remote-first startup
- non-sponsoring employer for contrast

### Jobs

Create:

- visa-sponsored software role
- healthcare role
- graduate role
- remote role
- role without sponsorship

### Candidates

Create sample candidates with:

- complete profile
- incomplete profile
- visa sponsorship need
- different skill sets

Do not use real identities.

### Applications

Create sample statuses:

- draft
- submitted
- viewed
- shortlisted
- interview
- rejected

### Messages

Create application-linked candidate/employer threads.

## Rule

Seed data should help test UI states: empty, partial, active, error, and complete.
