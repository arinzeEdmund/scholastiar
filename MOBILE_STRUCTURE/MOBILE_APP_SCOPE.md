# Mobile App Scope

Status: Mobile product scope

## Primary Audience

The first mobile app should serve applicants and candidates.

Before the native mobile app is built, `STRUCTURE/BUILD_GUIDE/PWA_FIRST_WEB_APP.md` should provide an app-like mobile web experience for the same applicant workflows.

Primary users:

- job seekers looking for visa-sponsored or relocation-friendly jobs
- students seeking universities and scholarships abroad
- applicants seeking fellowships, grants, competitions, conferences, training, and awards
- users tracking deadlines and application readiness
- users who want AI Apply Agent or Apply For Me support

## In Scope For Mobile MVP

- authentication and onboarding
- profile and mobility preferences
- destination country preferences
- opportunity discovery feed
- Jobs as the first full service
- universal opportunity cards
- opportunity detail pages
- save/unsave
- basic compare list
- readiness and success score display
- application time labels
- add to AI Apply Agent board
- add to Apply For Me board
- application tracker
- document checklist and upload
- push notifications
- deadline alerts
- pricing/plan entitlement display
- article/news/immigration update reader
- account settings

## Later Mobile Scope

- Universities
- Scholarships
- Fellowships
- Grants
- Competitions
- Conferences / Training
- Awards
- Migration agency discovery and booking
- full AI Apply Agent execution controls
- full Apply For Me campaign management
- in-app support/chat
- advanced offline mode

## Web-First Or Removed From Mobile MVP

- admin dashboard
- full employer dashboard
- full provider dashboard
- sponsorship campaign manager
- publishing editor/CMS
- deep analytics dashboards
- bulk opportunity upload
- pricing configuration admin
- moderation queues
- RLS/admin policy management

Mobile may show limited applicant-facing versions of employer/provider/sponsored content, but management screens should stay web-first.
