# Mobile Notifications

Status: Push notification and alert planning

## Purpose

Mobile notifications should turn Scholastiar.ai into an active opportunity assistant.

Notifications should be periodic and behavior-triggered, not random.

## Notification Types

- deadline reminders
- saved opportunity updates
- readiness score changes
- missing document alerts
- application status updates
- AI Apply Agent queue updates
- Apply For Me campaign updates
- new high-fit opportunity alerts
- article/news/immigration updates
- subscription/payment alerts
- security alerts

## Notification Rules

- users must opt in
- alerts must be relevant
- quiet hours should be supported later
- urgency should be reserved for real deadlines or action-needed events
- sponsored notifications require strict relevance and clear labeling

## Channels

Use:

- Expo Notifications
- in-app alerts
- email intelligence from `STRUCTURE/BUILD_GUIDE/EMAIL_INTELLIGENCE.md`

Mobile push and email should coordinate so users are not spammed.
