## Opportunity Card Mobile Rules

Mobile cards must be compact but actionable.

Required fields:

- title
- organization
- destination country
- key tags
- deadline
- application time
- success score
- save action
- primary action

Use secondary actions in an action sheet when space is tight.

## Visual Direction

Use `STRUCTURE/UI_BASE/signature_ui_base.md`.

Mobile UI should feel:

- calm
- premium
- direct
- touch-friendly
- score/readiness-driven
- action-oriented

Avoid:

- dense desktop tables
- tiny buttons
- multi-column layouts
- nested cards
- noisy gradients
- hidden sponsored labels
