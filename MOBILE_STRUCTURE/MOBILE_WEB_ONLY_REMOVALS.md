# Mobile Web-Only Removals

Status: Web-only and delayed mobile feature guide

## Keep Web-First

The following should remain web-first at launch:

- admin dashboard
- full employer dashboard
- full provider dashboard
- sponsorship campaign manager
- publishing editor/CMS
- full analytics dashboards
- moderation queues
- bulk opportunity import
- pricing configuration admin
- RLS/policy management
- database management

## Mobile Applicant Versions

Mobile can still show applicant-facing versions:

- sponsored labels on opportunity cards
- employer/provider profile detail
- migration agency detail
- article/news reader
- pricing/plan page
- Apply For Me board
- AI Apply Agent board

## Reason

Mobile should focus on repeated applicant actions. Table-heavy management, moderation, publishing, and admin work should stay in web dashboards until the mobile candidate experience is excellent.
